# 타이 인터네이션 (Thai Intonation)

한국말을 조금 하는 태국 친구 **민트(มิ้นท์)** 가 태국어 성조를 천천히 알려 주는 안드로이드 앱.

- `www/index.html` : 앱 화면 (수업 내용 `DAYS`도 이 파일 안에 있어요)
- `android/.../MintPlugin.java` : 휴대폰 음성(TTS)으로 읽기 + 음성 인식으로 발음 듣고 채점
- 코드를 `main`에 올리면 GitHub Actions가 APK를 만들어 **Releases**에 올려요.

## 설치
Releases에서 최신 `thai-intonation-vN.apk`를 휴대폰으로 받아 설치하세요.
처음 발음 채점을 할 때 마이크 허락을 물어봐요.
